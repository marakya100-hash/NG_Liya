# Как изготовить новый заказ

1. Скопируйте мастер-шаблон в отдельную папку заказа.
2. Получите разрешение законного представителя, имя ребёнка, имя в дательном падеже, возраст, фото, поздравление, подпись, фразу о подарке. Не собирайте адрес, школу, фамилию и дату рождения.
3. Подготовьте фото JPG, PNG или WebP; рекомендуемый размер около 900×1200, качество 85–90. Сохраните в assets/child/photo.webp (папку child можно создать). Не меняйте внешность ребёнка.
4. Откройте config.js в текстовом редакторе. Меняйте только значения справа от двоеточий. Сохраните файл в UTF-8.

| Поле | Что указать |
| --- | --- |
| storyId | Уникальный код заказа без личных данных, например order-001-2027. При изменении кода браузер начинает новое прохождение |
| childName | Имя в именительном падеже, до 45 символов |
| childNameDative | Имя для адреса на конверте: Софии, Артёму |
| childAge | Возраст числом |
| childGender | female или male; управляет формами спасла/спас, выбрала/выбрал |
| childPhoto | Относительный путь: ./assets/child/photo.webp. Латиница в пути без спецсимволов; поддерживаются PNG/JPG/JPEG/WebP |
| childPhotoPosition | Положение кадра, например center 35% |
| parentGreeting | Полный индивидуальный текст. Отделяйте абзацы последовательностью \n\n |
| parentSignature | Мама и папа / Тётя Олечка / другой отправитель |
| santaPersonalLine | Необязательная личная фраза Деда Мороза. Можно оставить пустой строкой |
| santaGreeting | Необязательное полное поздравление Деда Мороза вместо стандартного; подстановки {name}, {age}, {year}. При пустом значении используется стандартное |
| giftMessage | Точная фраза про настоящий подарок, полностью индивидуальная |
| newYear | Год праздника числом |

5. Если в тексте нужны двойные кавычки, ставьте перед ними обратную косую черту: \"слово\". Апострофы и «ёлочки» экранировать не нужно. Сохраняйте запятые между строками настроек.
6. Запустите `node tools/validate-config.mjs .` в папке заказа. Исправьте все errors; warnings прочитайте отдельно.
7. Пройдите сказку от начала до конца. Проверьте портрет, имя, подпись, скачайте грамоту. Повторите на телефоне.
8. Заархивируйте содержимое папки заказа, не меняя относительные пути. Для размещения архив предварительно распаковывается.
9. Передайте ссылку в соответствии с согласованной моделью доступа. По окончании срока хранения удалите персональные файлы, архивы и доступные копии репозитория.

## Если фото отсутствует

Проверка сообщит об отсутствии файла. В браузере зеркало покажет имя на сказочном фоне, если указанный путь корректен, но файл не загрузился. Если поле пути не заполнено или содержит неподдерживаемый формат, используется демонстрационный портрет: перед выпуском реального заказа это обязательно исправить.

## Сброс прогресса

В финале нажмите «Пройти сказку ещё раз». После перезагрузки стартовый экран также предлагает «Начать заново», если уже есть сохранённое прохождение. Новое storyId создаёт независимое сохранение. Личные данные не отправляются в аналитические системы.
