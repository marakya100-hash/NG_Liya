# Проверка заказа перед отправкой

- [ ] Законный представитель согласовал размещение, доступ и срок хранения.
- [ ] У заказа уникальный storyId.
- [ ] Верны имя, дательный падеж, возраст, пол, год.
- [ ] В зеркале именно согласованное фото, лицо не обрезано.
- [ ] Личные тексты и подпись заменены, демонстрационные данные удалены.
- [ ] Все три спутника выбираются; выбранный появляется далее.
- [ ] Все три маршрута отличаются; работают полёт и пропуск.
- [ ] Снеговик получает ровно семь предметов; повторное нажатие не увеличивает счёт.
- [ ] Семь огоньков собираются в фонарь, работает подсказка.
- [ ] Все три подарка соответствуют получателям; ошибка не наказывает ребёнка.
- [ ] Доброе желание зажигает звезду и гирлянды.
- [ ] Дед Мороз поздравляет по имени; письмо близких без обрезания.
- [ ] PNG грамоты сохраняется, верны имя и год, кириллица читается.
- [ ] Финальный подарок открывается и показывает нужную подсказку.
- [ ] При перезагрузке можно продолжить, мини-игры сохраняют найденное.
- [ ] Повторное прохождение сбрасывает задания и выбор спутника.
- [ ] Музыка включается и выключается, без неё всё работает.
- [ ] Нет боковой прокрутки при 320 px и на телефоне заказчика.
- [ ] Проверены Safari на iPhone и Chrome на Android, включая скачивание PNG.
- [ ] Проверка tools/validate-config.mjs прошла без errors.
- [ ] Все папки и локальные шрифты включены в архив.
- [ ] Ссылка соответствует обещанному уровню доступа.
- [ ] Запланировано удаление материалов после согласованного срока.
