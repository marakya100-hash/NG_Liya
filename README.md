# Секретная миссия Деда Мороза — мастер-шаблон v2.1

Полная статическая интерактивная сказка. Демо: София, 7 лет, Новый год 2027.

## Что входит

12 сюжетных экранов, три спутника, раскрытие портрета в зеркале, три маршрута полёта, перетаскивание семи крупных вещей к нарисованному снеговику, семь огоньков, три подарка, три добрых желания, два письма, грамота PNG 1800×1270, финальный подарок. Прогресс сохраняется в браузере. Звук выключен при открытии, включается кнопкой с нотой. Оригинальная синтезированная мелодия работает без аудиосервисов и внешних запросов.

## Как посмотреть

Разместите содержимое этой папки на статическом хостинге. Для локальной проверки удобно запустить `python3 -m http.server 8000` из этой папки и открыть http://localhost:8000. Сам сайт не требует Node.js или сервера приложений; простой HTTP-сервер нужен только для удобного локального просмотра. Прямое открытие index.html может ограничивать работу локальных шрифтов и сохранения в некоторых браузерах.

## Следующий заказ

Читайте `docs/customization.md`. Все персональные данные находятся в `config.js`. Для смены ребёнка программный код изменять не требуется.

## Размещение

Читайте `docs/publishing.md`. Для GitHub Pages в корень репозитория загружается **содержимое архива целиком**, включая assets, css, js, docs, config.js и index.html. Папки assets и fonts обязательны. Не загружайте ZIP одним файлом вместо его содержимого.

## Перед передачей

Запустите `node tools/validate-config.mjs .` из корня распакованного архива (нужен Node.js только для проверки). Затем пройдите чек-лист `docs/checklist.md`. Документ `docs/testing.md` описывает выполненную проверку и ограничения.

## Приватность

Демоверсия использует полностью вымышленный портрет. Аналитика и сторонние сервисы не подключены. Шрифты локальные. Сохранение прогресса происходит на устройстве посетителя. Для каждого заказа задавайте уникальный storyId.

Для реальных заказов не помещайте фото и поздравления в открытый репозиторий. Индексация запрещена метатегом и robots.txt, однако это не ограничивает доступ. Если покупателю обещается конфиденциальность, используйте хостинг с фактической авторизацией. Демо GitHub Pages подходит для неперсональных примеров. Срок хранения и удаление материалов согласуются с законным представителем.
