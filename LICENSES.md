# Ресурсы и условия использования

## Шрифты

Marck Script, Cormorant Garamond и Nunito распространяются по SIL Open Font License 1.1. Лицензии допускают использование в коммерческих веб-проектах и в изображениях, созданных с помощью шрифтов, при соблюдении условий OFL. Копии оригинальных OFL и сведений об авторах находятся в assets/fonts/*-OFL.txt. Файлы шрифтов загружены из Google Fonts (fonts.gstatic.com), лицензии — из официального репозитория google/fonts. Шрифты не переименованы и не изменены. Подключение происходит локально, без запросов к Google при просмотре сайта.

## Иллюстрации, сгенерированные для проекта

assets/cat.webp, fox.webp, dragon.webp, santa-room.webp, child-demo.webp, workshop.webp, tree.webp, sleigh.webp созданы инструментом ImageGen для этого проекта 30.10.2026. Коммерческое использование определяется применимыми условиями сервиса OpenAI; отдельная открытая лицензия на них не заявляется. Генерация не гарантирует уникальность изображения или исключительные авторские права. Портрет child-demo полностью вымышленный.

## Предоставленные пользователем референсы

assets/backgrounds/forest.webp, village.webp, square.webp, flight.webp, portal.webp — оптимизированные копии пяти приложенных пользователем изображений. Подтверждённой информации об их авторах и лицензиях нет. Перед коммерческим тиражированием следует подтвердить права либо заменить их изображениями с известными правами. Это единственный набор графики проекта, для которого происхождение не установлено. Демоверсия позволяет заменить эти файлы, сохранив имена.

## Векторные игровые элементы и программный код

Во второй редакции снеговик, предметы, получатели, фонарь, сани, ёлка, подарок, озеро и северное сияние — иллюстрации ImageGen в assets/premium/. SVG звезды и программное оформление созданы в рамках проекта. Векторные элементы и CSS-анимации не заимствованы из внешних библиотек. Экспорт грамоты формируется локально на Canvas.

## Музыка

Авторская синтезированная инструментальная последовательность и звуковые эффекты в js/audio.js созданы для этого проекта. Записей сторонних исполнителей и внешних музыкальных файлов нет. Музыка воспроизводится Web Audio API только после действия пользователя.

## Фото покупателя

Фотография реального ребёнка не входит в демоверсию. Для персонального заказа необходимы права и согласие законного представителя на согласованный способ использования и размещения.

## Промпты изображений

Финальные промпты и описание способа генерации приведены в docs/image-prompts.md. Основной способ — встроенный ImageGen; CLI/API-генерация не применялась.
